# Changelog

- Rebranded the application to **acousticvoid downloader**.
- Expanded the catalog from 36 to 90 tools across seven groups.
- Added Spokwn, Nirsoft, Eric Zimmerman, Orbdiff, and Generic Tools entries.
- Updated Eric Zimmerman downloads to the current `/net/` release paths.
- Replaced the dead FTK link with the official FTK Imager 4.7.3.81 release.
- Decoded percent-encoded `Content-Disposition` filenames, so FTK saves as `Exterro_FTK_Imager_(x64)-4.7.3.81.exe`.
- Simplified settings storage to `%LOCALAPPDATA%\acousticvoid\downloader\settings.json`.
- Kept the single-action, center-only UI with the acousticvoid mark.
